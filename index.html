06AI Operating System

I turned Claude into a kit factory.

Most people ask AI questions. I built a system that takes the systems I have already built, strips out the project-specific guts, wraps each one in a safe front door, tests it, packages it, and files it. A future me, a teammate, or an AI agent can then auto-deploy it. I call each one a kit.

DataSchema MappingMap any product to its exact data handles, then hand it to a coding agent. Built for my dad and delivered.
WebSite DeployUpdate a live website by talking to your AI. Diff, deploy, verify, with a confirm-the-diff guardrail.
AutonomyAuto-Auto EngineMake progress while you sleep. A heartbeat advances a roadmap on safety rails and self-kills when the goal is whole.
DevOpsGitHub ConnectorGitHub from chat without an MCP. One tokened script reads repos, pushes folders, opens PRs and issues.
ProcessCoordination & RecordsMany AI chats, one shared folder, no collisions. Deposit, reconcile, clean.
CloudCloud DeployShip an app to Cloud Run from chat via GitHub Actions, then watch it live.
The discipline that makes it work
01

Generic engine, concrete example. Every kit ships the reusable system plus one real filled-in instance, so it is never abstract.

02

A safe front door. One paste-in prompt or one command, guardrail built in. The receiver never has to understand the internals.

03

Credentials never ship. Tokens live in a file the connector only reads. Never printed, never pushed, payload-scanned before upload.

04

Test, record, repeat. Every connector is validated offline, deposited to a log, indexed, and zipped for handoff.
