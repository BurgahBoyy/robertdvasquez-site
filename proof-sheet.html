My AI operating system

I turned Claude into a kit factory

The kit factory, 6 kits in a standing library

  • I package systems I have built into reusable kits: strip the project guts, wrap a safe front door, test, file. A future me, a teammate, or an AI can auto-deploy them.
  • Schema Mapping, map any product to its exact data handles (built for my dad)
  • Site Deploy, update a live site by talking to your AI
  • Auto-Auto Engine, a heartbeat that advances a goal while you sleep and self-kills when done
  • GitHub Connector, GitHub from chat, no MCP
  • Coordination & Records, many chats, one folder, no collisions
  • Cloud Deploy, ship to Cloud Run from chat via GitHub Actions

How the factory runs

  • Generic engine, concrete example. Every kit ships the reusable system plus one real filled-in instance.
  • A safe front door. One prompt or one command, guardrail built in.
  • Credentials never ship. Tokens are read-only, never printed, never pushed, payload-scanned.
  • Test, record, repeat. Validated offline, deposited to a log, indexed, zipped.
  • Underneath: the auto-auto heartbeat, the VFE cascade, and custom connectors I built (build, GitHub, cloud, coordination).
